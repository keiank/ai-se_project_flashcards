# Flashcard App

The first project in the AI Software Engineering path on Tripleten. It is a web application that includes a few decks of flashcards, which can be reviewed with a card carousel.

## View Here

[Flashcard site](https://keiank.github.io/ai-se_project_flashcards/)

## Features

- Single page display
- Review each deck using a carousel
- Choose to review among multiple decks
- Add new decks of cards (coming soon!)
- Delete decks of cards
- Responsive design
- Open deck to display all cards
- Deletion confirmation modal

## Technologies Used

- HTML & CSS
- JavaScript
